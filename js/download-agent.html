What Nova can do on your laptop

  • Open apps (Chrome, Word, Notepad, etc.)
  • Open folders and search for files
  • Take screenshots

Safety

  • Runs only actions on an approved allowlist
  • Tied to your Nova account — no one else can use it
  • You can pause it anytime with the kill switch
  • Config is stored locally in %APPDATA%\Nova\config.json

Frequently asked

Is it safe?
Yes. The agent only runs actions from a fixed allowlist. It never opens files, never runs shell commands, and never touches anything you didn't ask for.
Do I need to keep it running?
No. Once you sign in for the first time, Nova Agent registers itself to start automatically with Windows. Just reboot your laptop and it runs silently in the background — you never need to open it again.
How do I know it's running?
Open Task Manager (Ctrl + Shift + Esc) → Startup apps tab → look for NovaAgent with status Enabled. Or open this page — if the green banner at the top says "running", it's active.
How do I turn off auto-start?
Create an empty file called nova.remove_startup on your Desktop. Next time the agent runs, it removes itself from Windows startup and deletes the file. Or open Task Manager → Startup apps → right-click NovaAgent → Disable.
Do I need to download it every time?
No. You only download NovaAgent.exe once. After that it stays on your machine and auto-starts with Windows. If you lose the file, you can re-download from this page.
Windows blocked it — what now?
Click "More info" → "Run anyway". This appears because the .exe isn't code-signed. It's normal for student projects and small apps.
How do I stop it?
Open Task Manager → find NovaAgent.exe → End task. This stops it until next reboot. To fully disable, use the auto-start removal method above.
Where is my login stored?
Locally at %APPDATA%\Nova\config.json. It contains your Nova user ID and access token. Never shared with anyone.
